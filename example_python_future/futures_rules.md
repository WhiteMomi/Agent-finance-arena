# 期货交易规则速查(面向 Agent 原型开发)

> 目的:用最短路径理解期货规则,并据此搭建一个**模拟撮合 + 账户风控 + Agent 决策**的原型。
> 说明:本文讲通用机制,并标注中国(上期所/大商所/郑商所/中金所/能源中心)与 CME 的常见差异。**具体保证金比例、手续费、涨跌停幅度、交易时间、持仓限额会随交易所公告调整,开发时请以交易所/期货公司最新公告为准,并做成可配置参数,不要写死。**
> 本文仅为技术与规则介绍,不构成投资建议。期货是高杠杆产品,可能损失超过本金。

---

## 1. 期货是什么

期货合约(Futures)是在**交易所**交易的**标准化合约**:约定在未来某个日期,以今天确定的价格买入或卖出一定数量的标的资产。

- **标的**:商品(螺纹钢、原油、黄金)、金融(股指、国债)、外汇等。
- **标准化**:合约规格(数量、品质、到期月份、交割地点)由交易所统一规定,你只决定"买/卖、几手、什么价"。
- **中央对手方**:交易所/结算所作为所有交易的对手方,买卖双方不直接承担对方违约风险,代价是你必须缴纳**保证金**并每日结算。
- **双向交易**:可以**做多**(买入开仓,看涨)也可以**做空**(卖出开仓,看跌),无需先持有标的。
- **多数投机者不会持有到交割**,而是在到期前**平仓**(做反向操作)了结。

## 2. 合约规格(Contract Spec)——数据模型的核心

每个品种都有一组规格,原型里应作为配置对象:

| 字段 | 含义 | 示例(仅示意,非实时数据) |
|---|---|---|
| `symbol` / 合约代码 | 品种+到期月份 | `rb2601`(螺纹钢 2026 年 1 月) |
| `multiplier` 合约乘数 | 每 1 个价格单位对应的金额/吨数 | 螺纹钢 10 吨/手 |
| `tick_size` 最小变动价位 | 价格最小跳动 | 螺纹钢 1 元/吨 |
| `tick_value` | 每跳盈亏 = tick_size × multiplier | 10 元/手/跳 |
| `margin_rate` 保证金率 | 占合约价值的比例 | 常见 5%~20%,交易所可调 |
| `price_limit` 涨跌停幅度 | 相对结算价的单日最大波动 | 国内常见 4%~10%;CME 为动态/分级机制 |
| `trading_hours` | 交易时段(含夜盘) | 随品种不同 |
| `last_trade_date` 最后交易日 | 此后不能再交易 | 按交易所规则 |
| `delivery` 交割方式 | 实物交割 / 现金交割 | 商品多为实物,股指为现金 |
| `fee` 手续费 | 按手固定或按成交额比例,平今可能更高 | 各品种不同 |

**盈亏基本公式**(每手):

```
多头盈亏 = (平仓价 - 开仓价) × multiplier × 手数
空头盈亏 = (开仓价 - 平仓价) × multiplier × 手数
合约价值 = 价格 × multiplier × 手数
```

## 3. 保证金与杠杆

期货**不需要支付全额**,只需缴纳保证金作为履约担保。

```
占用保证金 = 结算价(或成交价) × multiplier × 手数 × margin_rate
杠杆倍数 ≈ 1 / margin_rate        (例:保证金率 10% → 约 10 倍杠杆)
```

关键概念:

- **初始保证金**:开仓时需要的资金。
- **维持保证金**(CME 概念):账户权益低于此线触发追保。国内期货公司通常采用"风险度"监控(见下)。
- **账户权益(动态权益)** = 上日结存 + 平仓盈亏 + 持仓浮动盈亏 − 手续费 ± 出入金
- **可用资金** = 账户权益 − 占用保证金 − 冻结资金(委托冻结的保证金/手续费)
- **风险度(国内常用)** = 占用保证金 / 账户权益 × 100%
  - 通常 100% 以上即触发追加保证金,期货公司可能**强行平仓**。
- **杠杆放大盈亏**:价格波动 1% 在 10 倍杠杆下 ≈ 本金波动 10%。

> 保证金率在不同阶段可能不同:**交易所保证金** + **期货公司加收**;临近交割月、节假日前、市场剧烈波动时会上调;同一合约**随月份临近而提高**。

## 4. 每日无负债结算(盯市,Mark-to-Market)

这是期货和现货最大的机制差异,**撮合引擎必须实现**。

每个交易日收盘后,交易所/结算会员按**结算价**对所有持仓重新估值:

```
当日盯市盈亏(持仓)   = (当日结算价 - 上日结算价) × multiplier × 持仓手数   (多头;空头取反)
当日平仓盈亏(新开仓后当日平掉) = (平仓价 - 开仓价) × multiplier × 手数
```

- 盈亏**每天实际划转**到资金账户(盈利增加可用资金,亏损直接扣减)。
- 若权益不足以维持保证金 → **追保通知** → 次日规定时间内未补足 → **强平**。
- **结算价**:国内多为**当日成交量加权平均价**(中金所为最后一小时 VWAP);CME 为交易所根据收盘区间等规则确定。原型里可简化为"当日收盘价"或"日内 VWAP",并做成可替换策略。
- **昨结算价**是计算涨跌停、当日盈亏的基准,而不是昨收盘价(国内)。

## 5. 开仓、平仓、持仓

- **开仓**:建立新持仓(买开 = 开多,卖开 = 开空)。
- **平仓**:对已有持仓做反方向交易(卖平 = 平多,买平 = 平空)。
- **净持仓 vs 双向持仓**:
  - 国内大多数品种可**同时持有同一合约的多单和空单**(锁仓),保证金按规则可能分别或部分抵扣。
  - CME 等多采用**净头寸**:买卖自动抵消。
  - 原型需决定账户模型,建议**多空分开记录**(`long_qty`、`short_qty`),再按需要对冲。
- **今仓 / 昨仓**(国内重要):
  - 上期所、能源中心的部分品种要求**区分平今、平昨**,平今仓手续费可能显著更高(甚至是开仓的数倍)。
  - 下单时需指定开平标志:`OPEN` / `CLOSE` / `CLOSE_TODAY` / `CLOSE_YESTERDAY`。
- **持仓量(Open Interest)**:市场所有未平仓合约的**单边**数量,反映资金参与度。
- **成交量**:当期成交的手数。

## 6. 订单类型与撮合规则

### 6.1 常见订单类型

| 类型 | 说明 |
|---|---|
| 限价单 Limit | 指定价格,只在该价或更优价成交,未成交则挂单 |
| 市价单 Market | 按对手盘最优价立即成交(国内部分交易所对市价单有限制或需转限价) |
| 止损单 Stop | 价格触及触发价后转为市价/限价单 |
| 止盈 / 止损止盈组合(OCO) | 一方成交则另一方撤销 |

### 6.2 订单有效期(TIF)

- **GFD / DAY**:当日有效(国内最常见)
- **GTC**:撤销前一直有效(CME 支持,国内一般不支持)
- **FAK**(Fill And Kill):立即成交可成交部分,剩余撤销
- **FOK**(Fill Or Kill):要么全部立即成交,要么全部撤销

### 6.3 撮合原则(集中竞价)

1. **价格优先**:买价高者、卖价低者优先成交。
2. **时间优先**:同价位先报单先成交。(CME 部分品种为按比例分配,需看合约规则)
3. **成交价**:国内采用**最高买价、最低卖价、前一成交价三者取中间值**的规则(买价 ≥ 卖价时成交)。原型简化:撮合时按**被动方挂单价**成交即可。
4. **集合竞价**:开盘前有集合竞价时段(国内:夜盘/日盘开盘前),通常按**最大成交量**原则确定开盘价。

### 6.4 报单前检查(风控,必须实现)

- 价格是否在**涨跌停范围**内
- 价格是否为**最小变动价位的整数倍**
- 手数是否超过**单笔最大下单量**
- **可用资金**是否足够(新开仓需冻结保证金 + 手续费)
- 是否超过**持仓限额**
- 合约是否在**可交易状态**(非到期、非停牌、在交易时段)
- 平仓单是否有**足够可平仓位**

## 7. 涨跌停板与熔断

- **涨跌停板**:价格不能超出 `昨结算价 × (1 ± limit%)`。
  - 触及涨停:买单无法成交更高价,卖盘稀少;可能出现"封板",卖单难以成交(对多头平仓不利,极端情况会出现连续涨跌停、**无法平仓**的风险)。
  - 连续涨/跌停时,交易所常**扩板并提高保证金**,甚至启动强制减仓。
- **熔断/限价机制**:CME 对股指等采用分级熔断与动态价格带(具体阈值以交易所公告为准)。
- **原型实现**:在撮合前判断 `price` 是否越界,越界则拒单;在涨停价挂买单时,模拟"封板"可自定义成交概率。

## 8. 强制平仓与风控

强平触发场景(任一):

1. 客户权益不足,**风险度超限**且未按时追保;
2. 持仓超出**持仓限额**;
3. 违规交易 / 违反交易所规则;
4. 临近**交割月未按要求平仓**(个人客户通常需要在交割月前平仓);
5. 当日结算后出现**穿仓**(权益为负)。

> **穿仓**:亏损超过账户全部权益,账户变为负资产,需要向期货公司补足,这是期货区别于普通股票的重大风险。

强平顺序(常见实现):先撤销所有挂单 → 优先平**亏损/占用保证金最大**的持仓 → 逐步平仓直至风险度回到安全线以下。

## 9. 合约月份、到期与移仓(Roll)

- 同一品种有多个到期月份合约(如螺纹钢常见 1、5、10 月为主力月)。
- **主力合约**:成交量/持仓量最大的合约,流动性最好。原型中应有"选择主力合约"的逻辑。
- **近月 / 远月**:近月合约流动性、价格波动更大,临近到期保证金上调;远月合约价格受**基差**、持有成本影响。
- **移仓换月**:持仓接近到期时,需要把仓位转到下一个合约:
  1. 平掉当前月合约;
  2. 在下一合约开同方向仓位。
  > 价差(换月价差)会产生**换月成本**,需要在回测中计入。
- **展期收益(Roll Yield)**:当远月 > 近月(Contango,升水结构)时,多头移仓有成本;当远月 < 近月(Backwardation,贴水结构)时,多头移仓有收益。

## 10. 交割(了解即可)

- **实物交割**:多头收到货物(仓单)并付款,空头交付仓单。国内**个人投资者不能参与交割月的持仓**(通常需在交割月前最后交易日前平仓),机构有套保交割通道。
- **现金交割**:如股指期货,到期按**交割结算价**以现金结算差价,无需实物。
- 原型建议:**强制规则 = 最后交易日前 N 日必须平仓或移仓**,避免模拟交割逻辑。

## 11. 交易时间(以国内为例,具体以交易所公告为准)

- **日盘**:9:00–10:15,10:30–11:30,13:30–15:00(股指/国债期货时间不同)。
- **夜盘**:部分品种 21:00 开始,收盘时间随品种不同(23:00 / 次日 1:00 / 2:30 等)。
- **休市**:周末、法定节假日,节假日前通常**上调保证金**、**提高涨跌停板**。
- **交易日 vs 自然日**:夜盘属于**下一个交易日**。这是原型里最容易写错的一点,需要建立**交易日历**(Trading Calendar)。
- CME 为近 24 小时交易(周日晚至周五晚),每日有短暂结算休市。

## 12. 费用

- **手续费**:按手收固定金额,或按成交金额的万分比;开仓、平仓、平今仓可能不同。
- **交易所手续费 + 期货公司加收**。
- **滑点**:成交价与预期价的偏差,回测/模拟必须考虑。
- **资金成本**:一般无利息(保证金不计息或按协议),但**持有现货对冲**时有资金成本。

## 13. 限额与监管

- **持仓限额**:按品种、客户类型(自然人 / 机构 / 套保)限制单一合约最大持仓,临近交割月更严格。
- **大户报告制度**:持仓达到一定规模需向交易所报告。
- **程序化交易监管**:国内对**程序化/高频交易**有报告与监控要求(需报备),**自动化交易需符合交易所及期货公司规则**,实盘前务必了解合规要求。
- **适当性管理**:开户需通过知识测试、资金门槛,并有风险揭示。

## 14. 术语速查

| 术语 | 含义 |
|---|---|
| 多头 / 空头 | 持有买入头寸 / 卖出头寸 |
| 一手 | 一份标准合约 |
| 基差 | 现货价 − 期货价 |
| 升水(Contango) | 远月价格 > 近月价格 |
| 贴水(Backwardation) | 远月价格 < 近月价格 |
| 套保 / 套利 / 投机 | 对冲现货风险 / 利用价差获利 / 方向性博弈 |
| 价差(Spread) | 两个合约价格之差(跨期、跨品种) |
| 结算价 | 用于每日盈亏和保证金计算的价格 |
| 追保 | 保证金不足,要求补充资金 |
| 强平 | 强制平仓 |
| 穿仓 | 亏损超过账户权益 |
| 持仓量 OI | 市场未平仓合约总量 |
| 锁仓 | 同时持有同一合约的多单和空单 |

## B. 数据结构(Python 示意)

```python
from dataclasses import dataclass, field
from enum import Enum

class Side(Enum):
    BUY = "BUY"
    SELL = "SELL"

class Offset(Enum):          # 开平标志
    OPEN = "OPEN"
    CLOSE = "CLOSE"
    CLOSE_TODAY = "CLOSE_TODAY"

@dataclass
class ContractSpec:
    symbol: str
    multiplier: float
    tick_size: float
    margin_rate: float
    limit_pct: float             # 涨跌停幅度
    fee_open: float              # 开仓手续费(按手)
    fee_close: float
    fee_close_today: float
    last_trade_date: str
    cash_settled: bool = False

@dataclass
class Position:
    symbol: str
    long_qty: int = 0
    short_qty: int = 0
    long_avg: float = 0.0
    short_avg: float = 0.0
    long_today: int = 0          # 今仓,用于平今手续费
    short_today: int = 0

@dataclass
class Account:
    balance: float               # 静态权益(上日结存±出入金±已实现盈亏)
    positions: dict = field(default_factory=dict)
    frozen: float = 0.0          # 委托冻结资金

    def equity(self, prices, specs):
        floating = 0.0
        for sym, p in self.positions.items():
            s, px = specs[sym], prices[sym]
            floating += (px - p.long_avg) * s.multiplier * p.long_qty
            floating += (p.short_avg - px) * s.multiplier * p.short_qty
        return self.balance + floating

    def margin_used(self, prices, specs):
        total = 0.0
        for sym, p in self.positions.items():
            s, px = specs[sym], prices[sym]
            total += px * s.multiplier * s.margin_rate * (p.long_qty + p.short_qty)
        return total

    def available(self, prices, specs):
        return self.equity(prices, specs) - self.margin_used(prices, specs) - self.frozen

    def risk_ratio(self, prices, specs):
        eq = self.equity(prices, specs)
        return self.margin_used(prices, specs) / eq if eq > 0 else float("inf")
```

## C. 报单前风控伪代码

```python
def pre_trade_check(order, account, spec, prices, prev_settle, now):
    # 1. 交易时段 & 合约状态
    assert is_trading_time(spec.symbol, now), "非交易时段"
    assert now.date() <= spec.last_trade_date, "合约已过期"

    # 2. 价格合法性
    up, down = prev_settle*(1+spec.limit_pct), prev_settle*(1-spec.limit_pct)
    assert down <= order.price <= up, "超出涨跌停"
    assert abs(order.price/spec.tick_size - round(order.price/spec.tick_size)) < 1e-9, "不满足最小变动价位"

    # 3. 开仓需资金,平仓需可平仓位
    if order.offset == Offset.OPEN:
        need = order.price*spec.multiplier*spec.margin_rate*order.qty + fee(order, spec)
        assert account.available(prices, {spec.symbol: spec}) >= need, "资金不足"
    else:
        pos = account.positions.get(spec.symbol)
        closable = pos.long_qty if order.side == Side.SELL else pos.short_qty
        assert closable >= order.qty, "可平仓位不足"

    # 4. 持仓限额、单笔最大量等
    ...
```

## D. 每日结算流程

```
1. 计算当日结算价(简化:收盘价或日内 VWAP)
2. 对所有持仓:当日盯市盈亏 = (今结算价 - 昨结算价) × 乘数 × 持仓
              (当日新开仓则用 开仓价 作为基准)
3. 更新账户 balance(盈亏实际划转),扣除手续费
4. 将持仓的"成本价"重置为今结算价(这是盯市后国内平台的常见展示口径)
5. 今仓 → 昨仓
6. 计算风险度:> 阈值 → 触发追保标记;次日仍未补足 → 强平
7. 检查合约到期日:临近则要求移仓/平仓
8. 昨结算价更新为今结算价,用于下一日涨跌停计算
```

## E. 给 LLM Agent 的"工具"设计建议

让 Agent 通过**受约束的工具**交互,而不是直接改账户状态:

| 工具 | 说明 |
|---|---|
| `get_quote(symbol)` | 最新价、买卖盘、涨跌停价 |
| `get_kline(symbol, period, n)` | K 线 |
| `get_contract_spec(symbol)` | 合约规格(乘数、保证金率、到期日) |
| `get_account()` | 权益、可用资金、风险度 |
| `get_positions()` | 持仓、浮动盈亏 |
| `place_order(symbol, side, offset, price, qty, tif)` | 报单,先过 `pre_trade_check` |
| `cancel_order(order_id)` | 撤单 |
| `get_risk_state()` | 距强平线距离、距交割月天数 |

**务必让规则由代码硬约束,不要依赖 Prompt**:涨跌停、资金、持仓限额、强平都在撮合/风控层强制执行,Agent 只能"提交意图"。

## F. 建议的开发顺序(MVP → 完善)

1. **单合约、单账户、日 K 数据**:实现开平仓 + 盈亏 + 保证金。
2. 加入**手续费、滑点、涨跌停**。
3. 实现**每日结算与盯市**(核心)。
4. 加入**追保 / 强平 / 穿仓**逻辑。
5. 加入**多合约 + 主力合约选择 + 移仓**。
6. 加入**订单类型、TIF、部分成交**(用 Tick/分钟级数据)。
7. 接入 **LLM Agent**,先让它调用只读工具,再开放下单。
8. 写**回测报告**:收益、最大回撤、夏普、换手、爆仓次数。
9. (如需实盘)研究 **CTP 等柜台接口**与**程序化交易合规**要求,**先做仿真环境(SimNow 等)充分测试**。

## G. 常见坑

- 把 **夜盘** 算到自然日而不是**下一交易日**。
- 用**昨收盘**而不是**昨结算价**算涨跌停与当日盈亏。
- 忘记**乘数**(尤其不同品种的单位:元/吨、点数、美元/桶)。
- 没区分**平今/平昨**导致手续费算错。
- 回测使用**连续主力合约**但没处理**换月跳空**(价差缺口会产生虚假盈亏)。
- 没有模拟**涨跌停无法成交**、**滑点**、**流动性不足**。
- 忽略**穿仓**与**强平**,导致回测过于乐观。
- 让 LLM 直接决定"成交结果"而不是由撮合引擎计算。

## H. 数值小例子(用于单元测试)

假设:螺纹钢,乘数 10 吨/手,保证金率 10%,账户初始资金 100,000 元,忽略手续费。

1. 价格 3,500 元/吨买开 5 手:
   - 合约价值 = 3,500 × 10 × 5 = 175,000
   - 占用保证金 = 175,000 × 10% = **17,500**
   - 可用资金 = 100,000 − 17,500 = **82,500**
2. 当日结算价 3,550:
   - 盯市盈亏 = (3,550 − 3,500) × 10 × 5 = **+2,500**
   - 权益 = 102,500;占用保证金 = 3,550 × 10 × 5 × 10% = 17,750;风险度 ≈ 17.3%
3. 次日结算价跌至 3,300:
   - 当日盈亏 = (3,300 − 3,550) × 10 × 5 = **−12,500**
   - 权益 = 90,000;占用保证金 = 16,500;风险度 ≈ 18.3%
4. 若价格极端下跌至 2,000(假设无涨跌停):权益 = 102,500 + (2,000−3,550)×50 = 25,000,风险度 = 10,000 / 25,000 = 40%……继续下跌至权益接近 0 时风险度趋近 100% → 触发强平。
